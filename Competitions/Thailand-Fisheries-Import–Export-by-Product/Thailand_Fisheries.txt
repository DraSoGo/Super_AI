📦 ชุดข้อมูล: การนำเข้า–ส่งออกสินค้าประมงของประเทศไทย
Thailand Fisheries Import–Export by Product
รายละเอียดชุดข้อมูล (Dataset Description)

ชุดข้อมูลนี้แสดงข้อมูล การนำเข้าและส่งออกสินค้าประมงของประเทศไทย จำแนกตาม
- ประเทศคู่ค้า
- ประเภทสินค้า (HS Code)
- ปริมาณและน้ำหนักสินค้า
- มูลค่าการค้า
- เดือนและปีของการค้า

สินค้าในชุดข้อมูลประกอบด้วย สัตว์น้ำและผลิตภัณฑ์ประมง เช่น
- ปลา
- กุ้ง
- หอย
- ปลาหมึก
- สัตว์น้ำมีชีวิต
- ผลิตภัณฑ์แปรรูปจากสัตว์น้ำ

ข้อมูลนี้ช่วยให้สามารถวิเคราะห์ได้ว่า
- ประเทศใดเป็น ตลาดส่งออกสินค้าประมงสำคัญของไทย
- ไทย นำเข้าสัตว์น้ำชนิดใดมากที่สุด
- โครงสร้างการค้าสัตว์น้ำของไทยเป็น ผู้ผลิต (Net Exporter) หรือ ผู้บริโภค (Net Importer) ในสินค้าแต่ละประเภท
- การค้าสัตว์น้ำ เปลี่ยนแปลงตามฤดูกาลอย่างไร
ระบบบัญชีข้อมูลภาครัฐ (Government Open Data)

🗂 ที่มาของข้อมูล (Data Source)
ข้อมูลจาก
🔗 https://data.go.th/dataset/impexp_product
เป็นข้อมูลสถิติ การนำเข้าและส่งออกสินค้าประมงของประเทศไทย จำแนกตามประเทศคู่ค้าและประเภทสินค้า

📑 Data Dictionary

Field = Description
year = ปีของข้อมูล (พ.ศ.)
month = เดือนของข้อมูล (1–12)
heading11 = รหัสสินค้า HS Code สำหรับสินค้าประมง
countryID = รหัสประเทศคู่ค้า
countryNameTH = ชื่อประเทศคู่ค้า
weight = น้ำหนักสินค้า (กิโลกรัม)
quantity = จำนวนสินค้า
price = มูลค่าการค้า (บาท)
tradeflow = ประเภทการค้า (1 = Export, 2 = Import)
productDetailEN = รายละเอียดสินค้า (ภาษาอังกฤษ)
productDetailTH = รายละเอียดสินค้า (ภาษาไทย)
ETL_DATE = วันที่นำข้อมูลเข้าสู่ระบบ

🧠 โจทย์วิเคราะห์ข้อมูล (Challenge Questions)
ข้อ 1 — ตลาดส่งออกสินค้าประมงของไทยอยู่ที่ไหน?
Major Trading Partners
โจทย์
จากข้อมูลมูลค่าการค้า จงสร้างกราฟที่แสดงให้เห็นว่า
- ประเทศใดเป็น ตลาดส่งออกสินค้าประมงสำคัญของไทย
- ประเทศใดเป็น แหล่งนำเข้าสัตว์น้ำหลักของไทย
- และประเทศใดที่ไทย เกินดุลหรือขาดดุลการค้า ด้านสินค้าประมงอย่างชัดเจน


🦐 ข้อ 2 — สินค้าประมงชนิดใดคือหัวใจของการค้าไทย?
Fisheries Product Structure
โจทย์
จงสร้างกราฟที่แสดง โครงสร้างสินค้าประมงของไทย โดยจัดกลุ่มตาม HS Code
เพื่อแสดงให้เห็นว่า
- สินค้าประเภทใดที่ไทย ส่งออกมากกว่านำเข้า (Net Export)
- สินค้าประเภทใดที่ไทย ต้องพึ่งพาการนำเข้า (Net Import)

📈 ข้อ 3 — การค้าสัตว์น้ำมีฤดูกาลหรือไม่?
Seasonal Trade Pattern
โจทย์
จากข้อมูลรายเดือนตลอดปี 2568
จงสร้างกราฟที่แสดง
- แนวโน้มการเปลี่ยนแปลงของ Import และ Export สินค้าประมง
- ระบุให้ได้ว่าเดือนใดคือ ช่วงการค้าสูงสุด (Peak) ช่วงการค้าต่ำสุด (Low)
พร้อมตั้งสมมติฐานว่า
ปัจจัยใดอาจอธิบายรูปแบบดังกล่าว
เช่น
- ฤดูกาลจับสัตว์น้ำ
- ฤดูกาลเพาะเลี้ยง
- ความต้องการตลาดโลก
- เทศกาลการบริโภค
